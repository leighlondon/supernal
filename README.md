# supernal

A cosmic and celestial theme.

## Building

```shell
# the build script is in the makefile

# to compile the new themes/*.json
$ make
```

## Packaging

```shell
# to cut a new version, update the version id in `package.json` and commit

# package up the .vsix
$ make pack
```

## Experimental

There's an experimental Kakoune theme being emitted too.
